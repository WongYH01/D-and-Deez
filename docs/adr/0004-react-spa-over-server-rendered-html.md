# React single-page app over server-rendered HTML

The web UI is a React and TypeScript single-page app built with Vite in `src/web`, styled with Tailwind v4 and shadcn/ui on Base UI, and served by FastAPI as a static bundle at `/`. The first design used server-rendered HTML with htmx and said a React front end could replace it later. We chose React now because the UI is meant to keep growing (more screens in v2, a voice client in v3), and building on a component framework from the start is cheaper than rewriting server-rendered pages later. It also keeps the server a pure JSON and event-stream API, the same one curl and the voice client use. The cost is a Node build stage in the Dockerfile and a second test runner (Vitest) next to pytest. Screens use hash routes because the API already owns root paths such as `GET /campaigns`.
