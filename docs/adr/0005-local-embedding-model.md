# Scene recall embeds with a small local model that runs on modest hardware

Scene recall uses a small quantised ONNX embedding model (such as bge-small-en-v1.5, run through fastembed and onnxruntime) inside the container, with its weights downloaded at image build time. We chose this over a hosted embedding API (Voyage AI) to avoid a second API key and to keep embedding working offline, and it must stay within the limits of modest hardware such as a Pi 5 (arm64 wheels, no torch, peak memory under about 200 MB). This amends the v1 goal of "no local model inference" to "no local LLM inference". The cost is a larger image and a build-time model download. Embedding failure never fails a Turn: scene recall is skipped with a logged warning.
